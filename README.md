# steam-test

Steam üzerinden arkadaşlarla birlikte oynanan bir co-op korku oyunu denemesi. Oyuncular bir denizaltıyla dalış yapıyor, aşağıda da onları kovalayan bir yaratık var.

- Unity 6 (6000.4)
- Ağ: Mirror
- Steam entegrasyonu: Steamworks.NET

Kodların çoğu `Assets/Scripts` altında: `Network/GameManager.cs`, `Submarine/SubmarineDive.cs`, `AI/MonsterAI.cs`.

Çalıştırmak için projeyi Unity Hub'dan aç; Steam açıkken oyuna girebilirsin.
